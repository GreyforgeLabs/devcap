## What This Project Does

`devcap` scans a machine for installed development tools, extracts versions, and reports results in text, JSON, or markdown. It supports built-in and custom TOML profiles for filtering which tools to scan. It is a single Rust binary with no runtime dependencies; the built-in profiles are embedded at compile time. Version 0.3.0 rewrote the original Python implementation in Rust with identical CLI behavior and output formats.

Maintenance-only as a standalone project since September 2026. Preserve compatibility for existing users; new projects should declare required tools and versions in their own setup and CI. `check` verifies presence, not version constraints.

## Project Structure

```text
devcap/
  Cargo.toml          # crate metadata, pinned dependencies, release profile
  src/
    main.rs           # binary entry point
    lib.rs            # library root (module list)
    cli.rs            # CLI commands (scan, check, list-profiles)
    argparse.rs       # argparse-compatible option parsing (exact help/errors)
    scanner.rs        # core engine: PATH lookup, version probes, parallel scan
    process.rs        # bounded subprocess runner (timeouts, output caps, killpg)
    registry.rs       # tool definitions across 14 categories
    profile.rs        # TOML profile loader and schema validation
    toml.rs           # TOML parser (port of CPython tomllib, same errors)
    formatters.rs     # text, json, markdown output
    json.rs           # JSON writer matching Python json.dumps(indent=2)
    safe_text.rs      # terminal/Markdown sanitizing
    shlex.rs          # shlex.split port for version_flag parsing
    pycompat.rs       # CPython string/number semantics devcap relies on
    sys.rs            # the only unsafe code: small libc wrappers
    unicode_tables.rs # generated by scripts/gen_unicode_tables.py
    help/             # verbatim help and usage texts
    profiles/         # built-in TOML profiles (embedded with include_str!)
      full.toml
      python-dev.toml
      node-dev.toml
      rust-dev.toml
      devops.toml
      sysadmin.toml
  tests/
    cli.rs            # CLI integration tests
    golden.rs         # differential tests against captured Python outputs
    fixtures/         # golden outputs from the Python 0.2.1 implementation
  scripts/setup.sh    # idempotent setup (cargo build + verification)
  docs/benchmarks.md  # Python vs Rust measurements
  README.md           # human-facing docs
  STARTHERE.md        # this file
```

## Setup Prerequisites

- Rust 1.88+ with `cargo` (https://rustup.rs)

## Installation Steps

1. Clone: `git clone https://github.com/GreyforgeLabs/devcap.git`
2. Enter directory: `cd devcap`
3. Run setup: `./scripts/setup.sh` (or `cargo install --path . --locked`)

## Verification

```bash
devcap scan --format json
# Expected: JSON object with hostname, timestamp, platform, tools[], services[]

devcap check --profile python-dev
# Expected: exit code 0 when the profile's required tools are present;
# otherwise exit 1. The profile requires python3, pip, and git.
```

## Key Entry Points

- `src/cli.rs` — CLI entry point (`main_with()` function)
- `src/scanner.rs` — core scanning engine
- `src/registry.rs` — tool definitions (add new tools here)
- `src/profile.rs` — TOML profile loading
- `src/formatters.rs` — output formatting
